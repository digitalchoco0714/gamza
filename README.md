# 🥔 감자 (Gamza) - 포근한 우리 동네 중고거래

수파베이스(Supabase) Auth와 데이터베이스를 연동한 우리 동네 중고거래 웹 애플리케이션입니다.

## ✨ 주요 기능

1. **회원가입 및 로그인 (Supabase Auth)**
   - 이메일, 비밀번호, 필수 닉네임 기반 회원가입 및 로그인
   - 로그인 상태에 따른 상단 헤더 버튼(`로그인` ↔ `🥔 닉네임` / `로그아웃`) 자동 전환
2. **상품 목록 및 필터링**
   - 카테고리별 필터, 키워드(상품명·동네·작성자) 검색
   - `거래 가능만 보기` 체크박스 필터 및 `거래완료` 상품 흐림(Dim) 처리
3. **상품 등록 및 작성자 권한 관리**
   - 비로그인 상태에서 글쓰기 클릭 시 로그인 후 글쓰기 창 자동 연결
   - 본인 작성 게시글 상세 모달에서 **판매 상태 즉시 변경(`판매중` / `예약중` / `거래완료`)**, **수정**, **삭제** 지원
4. **관심 상품(찜) 및 동네 이웃 채팅**
   - 상품별 관심 등록/해제 및 실시간 동네 문의 채팅

## 📁 프로젝트 구조

```text
gamza/
├── index.html       # 메인 엔트리 HTML
├── css/
│   ├── common.css   # 공통 디자인 시스템 및 컬러 변수
│   ├── list.css     # 상품 목록 및 헤더 스타일
│   ├── detail.css   # 상품 상세, 작성자 관리 바, 로그인/채팅 모달 스타일
│   └── write.css    # 상품 등록/수정 모달 스타일
└── js/
    ├── config.js    # Supabase 연동 설정 (URL 및 Public Anon Key)
    ├── data.js      # Supabase Auth 및 REST API 데이터 스토어
    ├── list.js      # 목록 화면, 검색/필터 및 로그인 모달 제어
    ├── detail.js    # 상세 모달, 상태 변경/수정/삭제 및 채팅 제어
    └── write.js     # 상품 등록 및 수정 폼 제어
```
